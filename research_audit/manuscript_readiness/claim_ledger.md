## Conventions

**Status categories:**

| Status | Meaning |
|---|---|
| Established | Pre-specified or descriptive, traced to an artifact, reproduced where noted |
| Sensitivity | A robustness re-analysis of an established quantity |
| Exploratory-post-hoc | Any analysis not pre-specified as primary. This includes the planned but uncorrected Study 2 contrasts, marked "(planned)", and every `token_std` result, which was selected after seeing the data |
| Retired | Contradicted or superseded. It must not be used |
| UNVERIFIED | The value cannot be traced to a stored artifact. It has not been reconstructed |

**Uncertainty types:**

| Code | Meaning |
|---|---|
| FPB | Event-level paired bootstrap of fixed out-of-fold predictions (refitting excluded) |
| PS | Partition sensitivity: repeated outer partitions of the same events, not independent replications |
| — | No interval |

**Default cohort and fits.**
- **Study 1:** 103 events (52 campaign / 51 comparison), LR, outer stratified 5-fold with seed 42, inner 3-fold tuning of C over {0.01, 0.1, 1, 10}.
- **Fits:** BA from BA-tuned fits; log loss and AUC from log-loss-tuned fits.
- **Study 2 cohorts** are given as budget-specific (BS) or common (CO; 73 events, 28/45).

**Proposed wording** contains no causal language and is a target for the authors, not a draft.
